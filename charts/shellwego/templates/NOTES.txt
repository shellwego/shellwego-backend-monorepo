== Accessing the Control Plane ==

{{- if .Values.ingress.enabled }}

1. Get the ingress IP/hostname:
   export INGRESS_HOST=$(kubectl get ingress {{ include "shellwego.fullname" . }} \
     -o jsonpath='{.status.loadBalancer.ingress[0].hostname}' 2>/dev/null || \
     kubectl get ingress {{ include "shellwego.fullname" . }} \
     -o jsonpath='{.status.loadBalancer.ingress[0].ip}' 2>/dev/null)

2. Access the API at:
   http{{ if .Values.ingress.tls }}s{{ end }}://{{ (index .Values.ingress.hosts 0).host }}:{{ .Values.service.port }}

{{- if .Values.ingress.tls }}
   TLS is enabled. Certificates are managed via:
   {{- range .Values.ingress.tls }}
   - Secret: {{ .secretName }}
   {{- end }}
{{- end }}

{{- else }}

1. Forward the service port locally:
   kubectl port-forward svc/{{ include "shellwego.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }} &

2. Access the API at:
   http://localhost:{{ .Values.service.port }}

{{- end }}
